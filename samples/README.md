# GST paste samples

Raw tab-separated pastes from GST-style BOMs. Paste into the app and click **Organize list**, then drag rows to reorder.

| File | Machine / scenario | Notes |
|------|-------------------|-------|
| `grade-dozer-messy.txt` | D6XE grade dozer | Cables and harnesses before kit |
| `grade-dozer-ideal-order.txt` | Same quote | Example target order after manual drag reorder |
| `software-heavy-messy.txt` | Grade + option licenses | Licenses scattered in BOM |
| `cable-heavy-messy.txt` | Long cable BOM | Many cable lines mixed with brackets |
| `retrofit-small-messy.txt` | Small retrofit | No kit; loose parts only |
| `earthworks-dozer-complete.txt` | Generic Earthworks dozer | Full dozer BOM sample |
| `earthworks-dozer-missing-harness.txt` | Dozer base kit | Missing platform harness example |
| `earthworks-dozer-valve-no-ci.txt` | Dozer with valve add-on | Valve kit without CI510/CI520 example |
| `sps-rover-messy.txt` | Site Positioning rover kit | TSC710, R780, Siteworks modules, cables |

Replace these with real GST exports when available. Use **Auto-group** to sort lines and insert group headers; drag rows to fine-tune order.

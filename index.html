GST BOM Organizer (Beta)

Paste configuration, notes, and parts from GST (Guided Selling Tool) into a clean BOM (Bill of Materials). GST cannot go back — capture notes as you go.

Saved in this browser

Unofficial beta tool — not a Trimble product. Pricing shown here mirrors GST and is only as accurate as GST. Best practice is to verify pricing at store.trimble.com. Do not paste customer-confidential data into shared demos.

GST input

1. Paste configuration summary

From the final GST screen, copy the configuration block on the right. Each line is Label: then the value. Click Organize list — field order is chosen automatically for Machines or Site Positioning.

2. Paste configuration notes

Copy GST notes as you work through each step (serial range, factory fit warnings, licensing, SNM941 compliance, and so on). GST has no back button — if you miss a note, you start over. Web links stay as real addresses. Hold Ctrl- or ⌘-click a link to open it.

3. Paste parts table

In GST, select / highlight the parts table, copy it (Ctrl+C or ⌘C), then click in this box and paste (Ctrl+V or ⌘V).

Configuration

Edit fields below. Organize list sorts into GST order.

4. Clean list

No lines yet. Paste a list, then click Organize list.

Drag any row or column header to reorder. Drag a column edge to resize. A gold highlight shows where a reorder will land.

The clean table will show up here.

5. Copy organized text

Configuration, notes, and parts in one block. Select all (Ctrl+A or ⌘A) and copy (Ctrl+C or ⌘C), or click Copy all, then paste into your quoting tool or email.
